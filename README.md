# VEXORA GAME

Eine kleine Roblox-ähnliche 3D-Prototyp-Engine mit:
- First-Person Steuerung
- WASD-Bewegung
- Sprungmechanik
- 3D-Welt mit Boden und Blöcken
- Basic FPS/Position HUD

## Starten

```bash
npm install
npm run dev
```

Danach öffnet sich der lokale Server auf:

```bash
http://localhost:3000
```

## Steuerelemente

- W/A/S/D: Bewegen
- Space: Springen
- Maus: Blickrichtung ändern
- Klick: Pointer Lock aktivieren

## Tech-Stack

- TypeScript
- Vite
- Three.js

## Projektziel

Das ist der erste Prototyp für eine eigene Gaming-Plattform namens VEXORA. Der Fokus liegt aktuell auf einer einfachen 3D-Engine und Spielbarkeit, damit du als Testbasis ein Block-Game mit Steuerung und Bewegung bauen kannst.
