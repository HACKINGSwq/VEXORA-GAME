# VEXORA GAME

A small Roblox-like 3D prototype engine with:
- First-person controls
- WASD movement
- Jump mechanic
- 3D world with ground and blocks
- Basic FPS/position HUD

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/HACKINGSwq/VEXORA-GAME.git
cd VEXORA-GAME

# Install dependencies
npm install

# Start the development server
npm run dev
```

The local development server will open at:
```
http://localhost:3000
```

## Controls

- **W/A/S/D**: Move forward/left/backward/right
- **Space**: Jump
- **Mouse**: Look around (move your mouse to change view direction)
- **Click**: Lock the pointer to the game window

## Tech Stack

- **TypeScript** - Type-safe JavaScript
- **Vite** - Fast build tool and dev server
- **Three.js** - 3D graphics library

## Project Goal

VEXORA is a first prototype for an original gaming platform. The current focus is on creating a simple 3D engine and core gameplay mechanics as a testing foundation for a block-based building game.

## Development

### Available Scripts

- `npm run dev` - Start development server with hot reload
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally
